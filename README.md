# DSA with C++

This repository contains Data Structures and Algorithms problems
implemented in C++ for placement and interview preparation.

# Topics Covered

# 1. Data Structures
- Arrays
- Strings
- Linked List (Singly, Doubly, Circular)
- Stack
- Queue
- Deque
- Hashing
- Heaps / Priority Queue
- Trees
  - Binary Tree
  - Binary Search Tree
- Graphs
- Tries
- Disjoint Set (Union-Find)

# 2. Algorithms
- Searching Algorithms
  - Linear Search
  - Binary Search
- Sorting Algorithms
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
- Recursion & Backtracking
- Greedy Algorithms
- Divide and Conquer
- Sliding Window Technique
- Two Pointer Technique
- Bit Manipulation
- Dynamic Programming
- Graph Algorithms
  - BFS
  - DFS
  - Shortest Path Algorithms
  - Minimum Spanning Tree
- String Algorithms
- Mathematical Algorithms

## Goal
To build strong problem-solving skills and prepare for
product-based company interviews.
